# Tiamot Weather

Rain, snow, storms and the ground they leave behind, for the
[Tiamot](https://github.com/IridesiumResearch/Tiamot-Voxel-Game) voxel engine.
A standalone mod that sits beside the Spindle (Tiamot Default World) rather
than inside it, and runs on any other world with a plainer climate.

Written against the engine's public Lua API and nothing else. The rules that
shape it are in [`AGENTS.md`](AGENTS.md) (vendored from the engine's `api/`),
[`stubs/game.lua`](stubs/game.lua) is the API itself, and
[`docs/weather-plan.md`](docs/weather-plan.md) is the design and its numbers.

## Layout

```
mods/tiamot_weather/        the mod (this is what the engine loads)
  mod.toml                  manifest; the Spindle is an optional dependency, pinned < 0.2
  init.lua                  load order only
  config.lua                every number a designer might turn
  hooks.lua                 one engine registration per hook, many subscribers
  climate.lua               picks the adapter
  climate_spindle.lua       the Spindle's climate, mirrored: humidity, 4t(1-t) warmth, ground overrides
  climate_plain.lua         any other world
  blocks.lua                snow_layer, rainwater, and damp dirt and sand beside the Spindle
  controller.lua            weather(x, y, z, tick): the front, easing per square, overrides, the HUD line
  queue.lua                 the paced edit queue
  ground.lua                the sampler, snow layers, damp ground, puddles, both thaws
  fx.lua                    the sky, the rain, the loops, lightning, particle clouds
  commands.lua              /weather
  exports.lua               what other mods may read: game.exports("tiamot_weather")
  hud.lua                   the client-side HUD script
  textures/  sounds/        generated by tools/
tests/native/               the mod run through the engine's real script VM with a fake world
tools/                      the texture and sound generators (stdlib Python only)
docs/                       the plan, and what it needs from the engine
```

## Running it

The engine reads one mods directory (`mods_path`, default `game/`). Point it
at this mod with a directory junction so edits here are live:

```
mklink /J <engine>\game\tiamot_weather <this repo>\mods\tiamot_weather
```

Validate without launching the game:

```
cargo run -p server -- --check-mods game
```

And run the mod for real, headless, through the engine's VM with a fake
world around it (the engine checkout must sit beside this repo as
`../Tiamot`):

```
cargo run --offline --manifest-path tests/native/Cargo.toml
```

It checks the warmth curve against the Spindle's, forces a storm and watches
the HUD, the particle budget, the rain loop and thunder, restarts and resumes
the same front, lays a blizzard and a snowfall and checks their caps, thaws
snow near a player and by random tick, refuses edits to test the backoff,
leaves puddles and lets them go into rivers or boil off against lava,
puts a roof over everything, loads without the Spindle, and draws the HUD.

## Commands

| | |
|---|---|
| `/weather` | What it is doing where you stand, and why: kind, intensity, warmth, moisture, the front, the square |
| `/weather set <kind> [minutes]` | Force a kind on your 256-block square: `clear`, `cloudy`, `rain`, `storm`, `snow`, `blizzard`, `ash`, `ash_storm`, `dust` |
| `/weather clear` | Remove the force |
| `/weather forecast` | The next ten minutes at your square |
| `/weather drift` | Check the mirrored humidity against the Spindle's ground |
| `/weather stats` | The sampler's, queue's and particles' counts, to the server log |

`set` and `clear` are open to everyone while `config.commands` is true; the
engine has no operators yet.

## What is not here yet

- **Damp ground and puddles are `"auto"`:** off until the Spindle exports
  `add_soil_alias` or `add_harmless_fluid` and accepts the call. See
  [`docs/exports-contract.md`](docs/exports-contract.md), which also lists
  what Weather exports for other mods.
- **Clouds are particle puffs**, seen within about 128 blocks, so there is no
  cloud to the horizon. A real cloud deck is engine ask W2, the one thing on
  the sheet not built. Everything else — the darkened sky, the fog, the rain
  emitter, per-player loops, lightning — is the engine's own as of
  2026-09-17.
- **Per-player particles and sound** need asks W4 and W5.
